Waduh Bos, ini **geseran paradigma yang luar biasa keren!** Berarti "Suara Skansagiri" tidak kita arahkan untuk wadah demo atau komplain fasilitas saja, melainkan digeser total menjadi **Wadah Intelektual, Kreativitas, dan Literasi Digital** siswa. Ini jauh lebih berdampak positif dan pasti didukung 100% oleh Kepala Sekolah dan Pengawas SMK.

Anak SMK itu punya pemikiran yang sangat praktis dan solutif karena mereka dididik untuk langsung terjun ke dunia industri. Kalau wadah ini dibuka, karya mereka bakal sangat kaya.

Mari kita bongkar jenis-jenis karya penulisan dan ide siswa SMK yang bisa diwadahi di **Suara Skansagiri**:

## 📂 1. Klasifikasi Karya & Pemikiran Siswa SMK

Kita kelompokkan tulisan siswa menjadi beberapa rubrik/kategori agar mading digitalnya rapi dan enak dibaca:

### 🛠️ A. Jurnal Praktik & Opini Teknologi (Vokasi Teknis)

Ini tempat anak-anak jurusan (RPL, AKL, dll) pamer pemikiran teknis mereka.

* **Logbook Inspiratif / Cerita PKL:** Tulisan gaya blog tentang pengalaman seru atau penyelesaian masalah (troubleshooting) saat mereka Prakerin di industri. (Contoh: *"Cara Saya Mengatasi Error Server Database Saat Magang di Perusahaan X"*).
* **Review Teknologi/Sistem:** Pendapat siswa tentang perkembangan teknologi terkini yang relevan dengan jurusannya. (Contoh: Anak AKL nulis tentang *"Masa Depan Akuntansi di Era AI, Apakah Kita Bakal Tergantikan?"*).
* **Tutorial & Hacks:** Berbagi tips trik produktivitas atau coding/rumus cepat yang mereka temukan sendiri.

### 💡 B. Ruang Ide & Inovasi (Gagasan Liar Siswa)

Wadah untuk siswa yang kritis dan punya ide solutif untuk sekolah maupun lingkungan sekitar.

* **Esai Solutif untuk Sekolah:** Ide pengembangan fasilitas atau metode belajar. (Contoh: *"Ide Penerapan Smart Locker di Sekolah Menggunakan IoT"*).
* **Gagasan Startup / Bisnis (Khas TEFA):** Konsep bisnis kreatif yang dirancang siswa. (Contoh: Anak Pemasaran/Tata Boga urun ide tentang *"Konsep Kafe Literasi Berbasis Zero-Waste di Wonogiri"*).

### ✍️ C. Karya Sastra & Literasi Umum (Sisi Humanis)

Anak SMK juga punya rasa, Bos. Jangan sampai kreativitas seni mereka mati.

* **Cerpen & Puisi:** Wadah rilis karya fiksi tulisan tangan siswa.
* **Resensi Buku/Film:** Ulasan kritis terhadap buku yang mereka baca di perpustakaan sekolah atau film yang sedang tren.
* **Opini Bebas Populer:** Pendapat remaja tentang isu-isu sosial, kesehatan mental (*mental health*), atau motivasi belajar.

## 🔄 REVISI WORKFLOW (Sesuai Konsep Baru)

Karena isinya adalah karya tulis/ilmiah/opini, alur kerjanya berubah dari sistem "penanganan komplain" menjadi **Sistem Redaksi Majalah/Jurnal Ilmiah Mini**:

```
[Siswa Submit Karya/Ide] 
         │
         ▼
[Pilih Jenis Karya (Esai/Jurnal/Sastra/Opini)]
         │
         ▼
[Database: Status REVIEW] ➡️ (Masuk ke Dashboard Redaksi OSIS & Guru Pembina)
         │
         ▼
[Proses Kurasi/Penyuntingan]
         ├── Ditolak/Perlu Revisi ➡️ (Kasih feedback: "Bahasa kurang baku", dll)
         └── Disetujui (Approved)  ➡️ [Status: PUBLISHED]
                                         │
                                         ▼
                     [Karya Tayang di Feed "Suara Skansagiri"]
                                         │
                                         ▼
                 (Siswa lain bisa baca, kasih Like, & Bookmark)

```

## 📐 2. Update Skema Prisma (`schema.prisma`)

Tabel `Aspirasi` yang kemarin bernuansa keluhan kita ubah menjadi model `KaryaSiswa` yang lebih berorientasi pada konten literasi:

```prisma
model KaryaSiswa {
  id          String   @id @default(uuid())
  title       String   // Judul Karya / Esai / Ide
  slug        String   @unique // URL ramah SEO (contoh: /suara/ide-bisnis-tata-boga)
  content     String   @db.Text // Isi tulisan lengkap (bisa format Markdown)
  category    String   // 'JURNAL_VOKASI', 'ESAI_INOVASI', 'SASTRA', 'OPINI'
  status      String   @default("REVIEW") // REVIEW, PUBLISHED, REVISION, ARCHIVED
  feedback    String?  @db.Text // Catatan kurator jika butuh revisi sebelum tayang
  views       Int      @default(0) // Jumlah pembaca karya ini
  likes       Int      @default(0) // Jumlah apresiasi dari siswa lain
  
  // Relasi ke User (Siswa Pembuat Karya)
  authorId    String
  author      User     @relation(fields: [authorId], references: [id], onDelete: Cascade)
  
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

```
